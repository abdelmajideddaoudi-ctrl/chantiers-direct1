# Descriptions Morphix : artisans par métier

Images d'ambiance pour les posts Instagram de Chantiers Direct, une par métier de la plateforme.

## Réglages à utiliser à chaque fois

- **Mode** : Image
- **Modèle** : le plus réaliste proposé (« photo », « realistic », « portrait »)
- **Format** : 4:5 portrait (1080 × 1350), le même que les visuels de l'agent Instagram
- **Prompt négatif** (si le champ existe) :

```
mains déformées, doigts en trop, visage déformé, flou, dessin, cartoon, 3D, texte, logo, filigrane, marque visible
```

**Fin à ajouter à chaque description** (pour garder le même style sur tous les posts) :

```
, photo réaliste, lumière naturelle douce, appareil reflex 35 mm, légère profondeur de champ, couleurs chaudes, style photo professionnelle de magazine
```

Si les résultats sont décevants, essayez la même description en anglais : beaucoup de modèles d'IA comprennent mieux l'anglais.

## Avant de publier

- **Légende** : ajoutez une mention du type « Image illustrative générée par IA ».
- **Étiquette IA d'Instagram** : activez-la au moment de publier (Paramètres avancés > « Étiquette IA »).
- **Jamais** présenter ces personnes comme de vrais artisans inscrits ou de vrais clients, ni leur prêter un avis ou un témoignage.
- Vérifiez les mains, les outils et le texte éventuel sur l'image : ce sont les défauts les plus fréquents des images IA.
